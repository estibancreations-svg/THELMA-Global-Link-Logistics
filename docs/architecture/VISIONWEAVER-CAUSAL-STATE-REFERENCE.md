## Operational boundary

The Avatar State extension provides reusable design concepts for environmental sources, sound/structural paths, event/perception/response timing, enclosure boundaries, vehicle exterior/interior state and component continuity.

Keep operational telemetry separate from creative reference media. Never promote an automated movie descriptor, authored fictional power, exaggerated animated motion, illustrative world-fixture coordinate or guessed pressure/acoustic/material value to a fleet/safety measurement. Operational decisions require their own evidence and established authorization model.

The children's curriculum, style profiles, entertainment sound mix and avatar board production do not become logistics control policy. This note only links the shared design reference and clarifies the boundary; it adds no live dispatch/safety/telemetry functionality.
